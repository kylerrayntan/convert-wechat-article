# 验证范围

## 发布前已有验证

- 真实文档 A：18 个正文段落（含结尾空段）、23 个公式、无原图。
- 真实文档 B：127 个正文段落、138 个公式、3 张原 PNG 图片。
- 真实样本分别重复转换，固定环境下所有输出文件逐字节一致，输入文件未改变。
- 用户在 Safari 与微信公众号实际操作中确认整体复制后的效果可接受。

这些原始文档和生成文章均未随开源仓库发布。该结论是已有样本的实测结果，不代表所有 Word 文档、浏览器或未来公众号版本都已覆盖。

## 可公开复现的测试

执行 `python3 tests/run_checks.py`：

- 合成正文、上下标、分数、PNG 和 JPEG 的转换与校验。
- 200 个公式、3 张合成图片的计数完整性。
- 同一输入、参数、环境下输出字节一致，源文件未修改。
- 正文及模板特殊字符转义。
- 图片、文字及公式尺寸/段距 CSS 篡改检测。
- 隐藏文字、修订、表格、未知数学节点、缺失分母、超宽公式等明确拒绝。
- 图片缺失、损坏、裁剪、颜色变换和零尺寸等明确拒绝。
- 模拟 DOM 中的整篇剪贴板载荷、复制失败回退及事件清理。

测试样本由程序生成，只用于解析器回归，不是可交付的 Word 排版示例。页面测试使用模拟 DOM，不操作真实系统剪贴板或登录微信公众号。

GitHub Actions 配置包含 Linux / Python 3.10 / Node 22 与 macOS / Python 3.12 / Node 24。配置存在不代表云端已经运行通过；结果以仓库 Actions 记录为准。不同系统与字体不承诺逐字节一致。

## 自动校验的边界

校验不能独立证明数学等价，不能保证公众号不重新压缩图片。后续支持新的数学结构时，应增加正向、负向回归，并人工对照渲染公式。不要仅修改计数或忽略节点使测试通过。
