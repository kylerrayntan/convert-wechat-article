# 隐私与数据说明

## 公开仓库

发布源文件中未发现私人文章、原图、生成文章、个人电脑绝对路径、登录凭据或常见密钥格式。公开 GitHub 用户名 `kylerrayntan` 和许可证署名 `Miles` 用于项目归属，沿用已有公开项目。

本仓库不附带维护者的发布操作说明或本地检查日志。转换结果即便不在默认输出目录，也不要加入仓库；网页上传时需自行排除本地生成文件。

## 程序处理的数据

- 读取用户指定的 DOCX；正文、公式和图片在本地转换。
- 生成的 HTML 包含完整文章、图片和可复制文本，页面标题使用源文件名。
- `manifest.json` 保存源文件名、文件哈希、正文、公式表达式和资产信息；不主动记录源文件的完整路径。
- `report.json` 包含校验信息和运行环境；命令输出或失败日志可能包含本机路径或文档片段。
- 原图字节保留意味着原图内已有的 EXIF/XMP 等元数据也保留，可能包含位置、拍摄时间或设备信息。本工具不是图片脱敏工具。

这些输出和日志都应按文章资料管理。上传问题反馈前应使用可公开的最小复现样本，不要直接附上私人文章或完整 manifest。

## 联网和剪贴板

自有转换代码及页面脚本未发现文章上传、遥测、远程图床或外部脚本加载。HTML 的图片以内嵌数据保存，图片对照使用本地文件读取。首次 `npm ci` 从依赖注册表下载软件包；这与上传文章不是同一行为。

点击 Copy All 会把全文和图片写入系统剪贴板；系统剪贴板历史、跨设备同步和其他应用的访问方式由用户的系统设置决定。粘贴到微信公众号后，文章数据进入微信平台处理范围。

智能体客户端可能读取文件内容或命令输出，并按照其自身设置交给模型处理。本地转换程序不联网，不等于整个智能体服务完全离线。

本说明依据当前自有源代码和发布目录检查，不是对第三方依赖、所有客户端或操作系统的全面安全认证。
